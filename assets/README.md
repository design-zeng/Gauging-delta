# assets/

Static image assets used in the project README and documentation.

All generated plots use **Catppuccin** Mocha (dark) / Latte (light) palettes with
transparent backgrounds, served via `<picture>` tags for GitHub dark/light mode.

---

## Files

| File | Used in | Generated by |
|---|---|---|
| `readme_plot_{light,dark}.png` | `README.md` hero section | `scripts/plot_hero.py` |
| `scaling_runtime_{light,dark}.png` | `README.md` scaling section | `benchmarks/gen_scaling_plot.py` |
| `scaling_memory_{light,dark}.png` | `README.md` scaling section | `benchmarks/gen_scaling_plot.py` |

## Regenerating Plots

```bash
# Hero image (fast — runs clustering on 3 small datasets)
uv run python scripts/plot_hero.py

# Dendrogram (fast — runs clustering on flame dataset)
uv run python scripts/plot_dendrogram.py

# Scaling plots from cached benchmark data (fast — no re-benchmarking)
uv run python benchmarks/gen_scaling_plot.py --plot-only

# Scaling plots with fresh benchmarks (slow — re-runs all measurements)
uv run python benchmarks/gen_scaling_plot.py
```

All scripts accept `--theme light|dark|both` (default: `both`).
